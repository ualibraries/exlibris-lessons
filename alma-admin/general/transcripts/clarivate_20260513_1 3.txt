Hello. Alma sends a wide variety of letters to contacts such as patrons, vendors, and staff. You can fully configure the appearance of letters using letter templates. In this session, we'll learn how to manage letters, edit the text labels of a letter, edit a letter template, and preview letters with example user data. To configure the appearance of letters in Alma, go to Alma Configuration, General, Letters, Letters Configuration. Here you can see a list of all the types of letters sent by Alma. You can enable and disable letters. Alma keeps a copy of each letter sent to a user, which you can view in that user's Attachments tab. You can optionally add a retention period in days, after which Alma will purge the sent items of this letter type. Letters can be sent via email, SMS, or webhook. Some of these letters use Alma's default configuration, and some have been customized by your institution. To configure the appearance and content of a letter, click on the letter name, for example, Borrowing Activity Letter. On the configuration page for our letter, there are three main sections. The XSL section determines the structure of the letter, the Preview section shows what the letter will look like to an example patron, and the Accentual section contains example user data used to populate the preview. The Labels link opens a sliding panel, allowing us to edit the text labels used in the letter. You can preview the letter in any of the available languages for your institution, change the display width of the preview, and send this example letter to a specified email. The content of a letter is drawn from three sources, text labels, which make up the generic text of the letter, XSL components, which are shared graphic elements used across letters, and a letter XML generated by Alma with personalized user data. We can edit these various elements. Suppose we want to change the word Sincerely here to Cheers. We'll open the Labels sliding panel and find our Sincerely label. Click the Row Action tool and select Customize. Now we'll enter the new value. Then click Save to apply our changes. Now when we preview the letter, we can see the new value of our text label. Later in the session, we will show how to embed text labels in the letter template. If you want to make changes to the structure of your letter, you can do so in the XSL section. We are currently using Alma's default XSL template. Under Shared XSLs, we have the option to copy an XSL template created by other members in the Alma community. We're now using a shared XSL. In the same spirit, you can also contribute your own XSL template to the community. You can edit the XSL and save it as a draft. The XSL now has a draft indication on the top left. If you want to keep and publish your changes, click Save on the top right. Otherwise, if you made edits you don't want to keep, you can either click Remove Draft to return to the last saved XSL, or you can click Restore to reset the template to the Alma default. The XSL template itself does not normally contain any text values, but rather includes values from the three sources mentioned previously. The first source, Text Labels, is denoted by double at signs. For example, here is our Sincerely label. The second source, XSL Components, is denoted by an include tag. For example, this line includes the header component. In the preview, we can see this header consists of our institution logo. You can edit the header and other XSL components under Alma Configuration, General, Letters, Components Configuration. We won't show this now, but you can learn about it in the documentation. Take care when editing these shared components, since editing one component can affect many letters. The third source from which our XSL displays data is an XML with the specific user data generated for each letter. The XML contains things like the name of the patron and the titles and due dates of the loaned items. For example, these lines in our template extract data from the letter XML according to the specified path. To change the letter XML data, click Letter Examples to open the sliding panel. Here you can find a default letter example XML with no data, and you can add your own example letters. The simplest way to add an example letter is to click Add from System Letters and select one of the letters previously sent by Alma. Once your letter has been added, the preview will update with the new user data that has been taken from the XML. You can select to make this letter example the default preview. Now the preview will automatically display using this data. Besides adding from system letters, you can also upload your own XML files. If you made any changes, click Save. If you wish, you can edit the XML section to change the example data. When you're done configuring your letter, don't forget to click Save. Back on the letters configuration page, we can see the borrowing activity letter now appears as customized. Thanks for watching.
