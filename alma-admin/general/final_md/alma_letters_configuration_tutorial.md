# ALMA Letters Configuration: A Tutorial

## Overview

ALMA sends a wide variety of letters to patrons, vendors, and staff — covering loan notifications, overdue reminders, purchase orders, and more. The appearance and content of these letters can be fully configured using **letter templates**.

In this tutorial, you will learn how to:
- Enable and disable letter types
- Edit text labels within a letter
- Edit a letter's XSL template structure
- Work with letter preview data
- Understand the three sources of letter content

---

## Accessing Letters Configuration

Navigate to:

**ALMA Configuration → General → Letters → Letters Configuration**

This page lists all letter types sent by ALMA. From here you can:
- **Enable or disable** individual letter types
- Set an optional **retention period** (in days) — after which ALMA purges sent copies of that letter type from patron Attachment tabs
- View whether each letter uses ALMA's **default** configuration or has been **customized** by your institution

Letters can be delivered via **email**, **SMS**, or **webhook**.

> ALMA keeps a copy of each sent letter in the recipient user's **Attachments** tab.

---

## Opening a Letter for Configuration

Click on a letter name (e.g., *Borrowing Activity Letter*) to open its configuration page.

The page has three main sections:

| Section | Purpose |
|---------|---------|
| **XSL** | Defines the structure and layout of the letter |
| **Preview** | Shows what the letter will look like to an example patron |
| **Accentual (Letter Examples)** | Contains example user data used to populate the preview |

Additional options:
- **Labels** link — opens a sliding panel to edit the text labels used in the letter
- **Language selector** — preview the letter in any language available at your institution
- **Display width** — adjust the preview width
- **Send preview** — send the example letter to a specified email address

---

## The Three Sources of Letter Content

Letter content is drawn from three sources:

| Source | Notation in XSL | Description |
|--------|----------------|-------------|
| **Text Labels** | Double at signs (`@@label_name@@`) | Generic text such as greetings and sign-offs |
| **XSL Components** | `<include>` tag | Shared graphic elements used across multiple letters (e.g., institution logo in the header) |
| **Letter XML** | XPath expressions | Personalized user data (patron name, loan titles, due dates, etc.) generated by ALMA for each letter |

---

## Editing Text Labels

Text labels contain the static, non-personalized text of a letter (e.g., *Sincerely*, *Dear Patron*).

To change a label:
1. Click the **Labels** link to open the sliding panel.
2. Locate the label you want to change.
3. Click the **Row Action** tool and select **Customize**.
4. Enter the new value (e.g., change *Sincerely* to *Cheers*).
5. Click **Save**.

The updated label will immediately appear in the letter preview.

---

## Editing the XSL Template

The XSL template controls the structure and layout of the letter. By default, ALMA provides a standard template.

### Using a Community-Shared XSL
Under **Shared XSLs**, you can browse and copy XSL templates contributed by other ALMA institutions. You can also contribute your own templates to the community.

### Editing the XSL
1. Make changes directly in the XSL editor.
2. The template will display a **Draft** indicator in the top left while unsaved changes are pending.
3. When finished:
   - Click **Save** (top right) to publish your changes
   - Click **Remove Draft** to discard edits and return to the last saved version
   - Click **Restore** to reset the template to the ALMA default

### XSL Components
Shared graphic elements (such as the institution logo header) are referenced in the XSL via `<include>` tags. These components can be edited under:

**ALMA Configuration → General → Letters → Components Configuration**

> **Caution:** Editing a shared component affects every letter that includes it. Review all affected letters before making changes.

---

## Working with Letter Preview Data

The preview uses example XML data to simulate a real letter. You can customize this data to test your changes with realistic content.

### Adding a Letter Example

Click **Letter Examples** to open the sliding panel. Options include:

- **Add from System Letters** — select a letter previously sent by ALMA. This is the easiest way to get realistic example data.
- **Upload your own XML file** — manually provide a custom XML example.

Once added, the preview updates with the data from the selected example. You can set any example as the **default preview** so it loads automatically each time you open the letter.

You can also edit the XML directly in the panel to adjust the example data.

---

## Saving Your Changes

When finished configuring a letter, click **Save** at the top of the page.

Back on the Letters Configuration page, letters that have been customized will display a **Customized** indicator, distinguishing them from letters still using the ALMA default.

---

## Summary

ALMA's letter configuration system is flexible and layered — allowing you to change text labels for quick content updates, modify XSL templates for structural changes, and use realistic example data to verify your work in the preview. Understanding the three content sources (labels, XSL components, and letter XML) gives you full control over how every letter sent by your institution looks and reads.
