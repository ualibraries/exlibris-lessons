Hello. In Alma, calendars allow you to manage the open and close dates of the institution and its libraries. In this session, you will learn how to update calendars in Alma, as well as how to recalculate fines and fees based on calendar changes. To update calendars, including to add or change holiday dates, you'll go to Configuration, General, Libraries, Add a Library or Edit Library Information. Here you can update any library information. Right now, you're configuring the institution level. On the Libraries tab, you can add a new library by clicking Add a Library. Or you can edit a library organizational unit by opening the Row Action tool and selecting Edit. Click on the Calendar Management tab to see all current records. Here you can see a list of all the institution level calendar records, including hours, exceptions, and events. If you click on Full Calendar, it will give you a preview of the current calendar in day, week, or month views. This shows you the standard operating hours. And days that are blank are days that the library is closed. Click Back when you're done. Click Save if you have made any changes. Otherwise, click Cancel or click the back arrow. Click on the Institution Calendar Management tab again. Here you can edit a record by clicking on the Row Action tool and selecting Edit. And change the dates as needed. Please note that closed dates, such as holidays that are not on the same day every year, need to be edited annually. You need to add a new closure date for Independence Day. To create it, you'll click Add Record. There are three types of records you can make. Event, which is for special dates such as the end of the semester, or an exhibition. Events do not indicate whether the library is open or closed. Exception is used for open and closed dates and times, such as for holidays. And Standard Opening Hours is for regular dates and times that the library is open. After you select the type of record, fill in the information as needed. If you want to continue adding more records, click Add. If you're done, click Add and Close. Remember, only events and exceptions that apply to all libraries should be set at the institution level, as they will be inherited down. You can also import bulk changes by clicking Import. For more information about how to use this feature, please watch the session Update Library Opening Hours via Excel Import on our YouTube channel. Click Apply Changes to run the Calendar Changes job so that your updates will take effect. Click Save when you're done. Exceptions and events that are specific to an individual library within your institution are added at the library level. Select your library from the Configuring menu. Then go to Fulfillment, Library Management, Standard Opening Hours must be defined for each library in your environment. Fulfillment policies rely on the settings at this level. Standard Opening Hours are not inherited from the institution. You will also see that exceptions and events that are set at the institution level and have been inherited will have a green check in the Inherited column, and there will be no row action to a menu available for them. You need to create a new library-level calendar record for a staff training day, so you'll click Add Record. You'll select Exception as the record type, because this is a one-time occurrence. Then give it a description, and set the Valid From and Valid To fields. You could set specific hours that the library would be closed if the training were only going to be half a day. In this case, it's a full-day event. When you're done, click Add and Close. Then click Apply Changes to run the associated job to update the calendar, and then save so that the calendar reflects your updates. You now need to bulk update due dates due to an unexpected library closure. This process is also recommended if you make any changes to the calendar and want to apply them to the current loans to potentially waive any fines. You'll go back to Alma, Fulfillment, Advanced Tools, Loans, Bulk Change Due Dates. Enter in the relevant information including the library that the changes need to be applied to, what types of materials, the range of current due dates that should be changed, and what the new due date will be. Then click Change Bulk Due Date, and Confirm. Your job to change the due date of the item types you specified has now been added to the table below. You can also see previous bulk due date changes that have been completed. To keep your loans in line with any calendar changes, you should verify that the Loans, Due Date Correction After Calendar Change job is scheduled to run daily. You can check this by going to Admin, Manage Jobs and Sets, Monitor Jobs, and then click on the Scheduled tab. This is a fulfillment job, so you can use the dropdown to filter the list. This job should be scheduled to run every day. You can always run it manually when needed, as you just did in the previous step. You now know how to update calendars in Alma, as well as how to recalculate fines and fees based on calendar changes. Thanks for watching.
