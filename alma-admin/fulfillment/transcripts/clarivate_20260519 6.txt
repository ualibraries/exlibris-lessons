Hello. Alma allows you to configure various limits including patron and loan limits. Patron limits allow you to configure the maximum amount of fines, overdue items, requests, etc. that can be applied on their account before it is blocked until the fines are paid. Loan limits limit the number of items that a patron can simultaneously check out. These limits are dependent on user group, location, material type, etc. In this session, you will learn how to configure patron and loan limits. You need to create new patron and loan limits for high school students that will be using the University Library. You'll start by configuring the patron limits. You'll go to Configuration, Fulfillment, Patron Configurations, Patron Limits. Here you can see a list of user groups that patrons can be assigned to and the limits for each, such as graduate and undergraduate students, faculty, guests, etc. To add a new set of patron limits, click Add Row. Since you need to create a new user group for high school students that will be using the University Library, you'll select the high school student user group and enter in the maximum amounts for each field you want to apply. If you leave any of the boxes blank, no limit will be applied to that area. For more information about creating user groups, please see the corresponding session in the Alma Essentials Training in the Knowledge Center. When you're done, click Add Row. To delete a row, click on the Row Action Tool and select Delete, and then Save. To limit the number of items a patron can check out simultaneously, you have to add a loan limit rule on the Loan Limit Rule page. In the Configuration menu, you'll go to Fulfillment, Patron Configurations, Loan Limits. Here you can see a list of all of the current loan limit rules. Please note that these rules can only be configured at the institution level. Use the toggle button to enable or disable a rule. The arrow buttons allow you to move rules up and down, and will be assigned to patrons based on the first rule for which they meet the criteria. When you click on the Row Action Tool, you have the option to Edit, Duplicate, or Delete. Click Edit to make any changes to a rule. In the Editor, you can add input parameters to define the circulation transactions to which this rule will apply. The parameters can be based on one or more conditions relating to library location, item policy, material type, and user group. In the Output Parameters, you can change the loan limit that will apply when the conditions of the input parameters that you just set are satisfied. Click Save if you made any changes. To create a new rule, click Add Rule. You are required to enter a name. For this example, you'll align it with the Patron Limit user group you configured in the last step. Optionally, you can add a description if you'd like. Now you'll enter your parameters. Select User Group, and locate the user group you configured on the Patron Limits mapping table. In this case, it's High School Students. Add any additional parameters as needed. In this case, you need to set the item policy to 2-week loan. And then you'll set the loan limit. Now, any patron in the High School Students user group can only check out a maximum of 5 items with a 2-week loan limit. When you're done, click Save. Your new High School Students loan limit has been created, with the High School Student Patron Limit user group applied as one of the parameters. You now know how to configure patron and loan limits. Thanks for watching.
