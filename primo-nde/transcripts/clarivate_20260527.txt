Hello! As an administrator, you can configure what users see when they are using PrimoV by managing the various views. Views in PrimoV define everything you want to show the patron. It's where they can conduct searches, retrieve results, and access materials. You can have multiple views per institution, such as a test view, a demo view, and a production view. Or, each library branch could have a different view. There is no limit to the number of views. In this session, you will learn how to create a new view and edit an existing one. This session includes how to customize the links at the top, and how to customize the display of information and services in a brief record, and in a full record. Search configurations are covered in another session. Configuration for PrimoV is done through Alma. To access views, you'll go to Discovery, Display Configuration, Configure Views. Here you can see a list of all the views currently at your institution. The default view is marked by the blue radio button. This is the view used when staff use the display and discovery link from a record in Alma. To create a new view, you can open the row action tool and select Duplicate to make a copy of an existing view. This is great for creating a test view to try out tweaks of your current configurations. Or, you can create a new view, which is what we'll do. Click Add View. On the View Configuration page, all fields marked with a red asterisk are required. In the Define View section, the code is used to form the URL of the view. Please note that spaces and special characters are not supported. Add a name and a description if you'd like. In the General Attributes section, define how long the system should wait before logging out an idle guest user, as well as signed in users. Change the default language if needed. For more information about the additional attributes available, please visit the Knowledge Center. When you're done, click Save and Continue to save your work and keep editing or save to save, and go back to the list of views. And here's your new view. If you click on the row action tool for a view, you have several options available. Go to View will open that Primo V view in a new browser tab. To edit a view, select Edit. Here you can configure how Primo V will display to patrons. The General tab provides a basic overview, which shows the information you entered when you created it. Everything on the page is editable except the code, because it is linked to the URL for this view. The Links menu tab contains a list of the main menu links that are displayed in the persistent search bar at the top of the view. By the way, any section that has not yet been changed from its default settings will show Customize at the top. Click this to enable editing of the section. You can control if a link is visible or not with the toggle in the active column. Use the arrows to adjust the order. The label shows how the link will be displayed to patrons in Discovery. You can add new links by clicking Add Link, or edit an existing link by clicking the row action tool and selecting Edit. On the Search Profile Slots tab, you can choose the slots available to users to narrow down searches in Primo V. They are visible to the user in the drop-down next to the search box. The Advanced Search Configuration tab is where you can customize your options for advanced search. And Brief Results is where you can control Quick Filters, Facet Availability, Sort, and other Search Results page configuration elements. For more information about these tabs, please watch the Search Configuration session. The Brief Record Display tab allows you to customize the information and actions that appear for each record on the Brief Results page. The Display Fields section will always be four lines, but you can change their order as well as what is displayed on each. Drag and drop to change their order. To change the content of a line, click the row action tool and select Edit. You can change the delimiter if you would like a different symbol to separate elements. Use the checkboxes to display a summary and or a snippet with each brief record. In the Record Actions section, actions are grouped by type. Choose which action types to display and in what order. Click the row action menu to configure the actions within each group. The Full Record Services tab shows you all the possible sections in the order that they will appear when a patron views a title's full record. For each title, only the relevant sections will display. Use the checkboxes for a section to display expanded by default. Some sections have additional configuration options through the row action menu. The Manage Customization package is used to style the view colors and branding. Learn more in the User Interface Customization session. In this session, you learned how to view, create, and edit different parts of views for Primo V. Thanks for watching!
