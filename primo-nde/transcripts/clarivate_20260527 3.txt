Search allows users to find what they are looking for in Primo-V based on their search terms and any other selected facets. As an administrator, you can configure the options displayed in the user interface. When a user performs a search in Discovery, they can select a slot to search within. If more than one profile is configured for that slot, they can select a search profile. Each of these search profiles is a group of search scopes. When viewing the search results, users can further refine their search by resource type, with quick filters, and with the All Filters side panel. In this session, you will learn how to configure search scopes, profiles, and slots, as well as basic and advanced search, along with facets and sort. Scopes are groups of records that meet specific conditions, such as a particular resource type or library, a location in a library, or available electronic inventory. Search profiles are the containers for one or more scopes. These search profiles can then be grouped together in a slot, which appears to users if active for that view. For example, any time you search, you choose to search in a particular slot. In this case, select Alma University and Central Discovery Index, which is the search profile that includes the Alma University and Central Discovery Index scopes. When the results page loads, you can see the slot menu to the left of your search terms in the persistent search bar. The search slots are configured in Alma. Go to Discovery, Search Configuration, Search Profiles. This will bring you to the page of search profiles already configured in your system. The Search Profiles tab lists all the profiles configured at your institution. By default, PrimoV is preconfigured with several profiles, including All Catalog Records, Central Index Records, a profile that includes all records at your institution, and the Central Discovery Index, and Course Reserves. If you want to edit an existing profile, click the row action tool and select Edit. However, please note that we recommend that you do not edit an existing out-of-the-box profile. Custom local data scopes allow you to create scopes that limit searches in the local database to specific library metadata, such as resource type or availability. This is useful if you have a special collection that does not have its own library. You can create a special collection scope and then list them with a search profile. And the Other Indexes tab allows you to limit searches to third-party search indexes. After an index has been defined, you can then add it to a search profile. In this example, you want to create a new profile that will search in the science and physics libraries at your institution, so you'll click Add a Search Profile. You are only required to add a code and a display name. The globe icon allows you to assign translated display names for this profile. Now you'll add your scopes. Click Add Scope. In the Select Scope Type drop-down, you'll see a list of available campuses and libraries. This list is predefined and represents the different scope types available. For more information about valid scope types, please visit the Knowledge Center. If you had created a new scope in the Custom Local Data Scopes tab, you would be able to find it under Custom, Local Data. In this case, you'll select My Libraries, since you're creating a scope for the science library at your institution. Next, you'll select the science library from the second drop-down menu. If you want to continue adding libraries, click Add. Otherwise, click Add and Close. Click Save when you're done. And here's your new search profile. Next, let's look at how basic and advanced search options are configured, including how to create a slot that will use the search profile you just created. Start by navigating to Discovery, Display Configuration, Configure Views. Open the row action tool of the view you want to edit and select Edit. Basic search options are configured in the Search Profile Slots tab. This lists all the slots that will display in the drop-down menu next to the search box. You can toggle whether they are active or not, and change the order in which they display by using the arrows. To create your new slot, click Add a Slot. Here you'll give it a code, a name, and a description if you'd like. Then find your search profile in the Select Search Profiles for Slots section, and toggle to activate it. When you are done, click Save. Your new slot is now listed, and will display in PrimoV in the drop-down menu. Each part of advanced search is controlled by a section on the Advanced Search Configuration tab. The search slots were configured on the previous tab. The list of indexes determines the search index options. The list of resource types controls the corresponding drop-down. And the same goes for language, and for search operators. For example, this is the list of indexes, and the active ones appear in the first drop-down of the query. The options here are flexible, depending on the slot selected at the top. In this example, only when the Course Reserve slot is selected, Course Instructor and Course ID appear as options. This is configured in the Search Profile Slots column. Within each list, you can toggle individual fields on and off, and rearrange the order by using the arrows. Any changes you make here are saved automatically. The Brief Results tab is used to configure how search results can be faceted and sorted. These are commonly used quick filters that display above the brief results, where they are immediately accessible. Each will only display if toggled to active. Drag and drop to change the order. Facets in the All Filters side panel can be toggled on and off, and you can change their order by using the arrows. Values to display is how many of that type will be shown without expanding the facet. And the sort type determines how items within a facet will be sorted. Use the drop-down arrows to make changes to either of these. Scroll down to see the resource type's filters. As before, these can be active or not. You can edit them or change their order. Now you know how to configure search scopes, profiles, and slots, as well as how to configure both basic and advanced search, and how to configure facets and sort. Thanks for watching!
