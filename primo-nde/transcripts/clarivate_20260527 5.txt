Delivery is an important part of PrimoV. It's how patrons access the items they want. The delivery services provided are based on your Alma inventory. You can see some availability information from the brief record, but open the full record for more. In this session, you will learn how to configure three delivery service sections that appear in the full record. Request forms, location information, and links. The requests section can include several kinds of requests, depending on what is available for this particular item. A patron fills in a request form which can be customized in Alma. Open Configuration, Discovery. Under the Get It configuration section, select the form to customize. Digitization Request. Hold in Booking Request, Purchase Request, or Resource Sharing Request. For example, select Digitization Request. Choose which fields will be visible, and whether they will be mandatory. Let's make this copyright declaration mandatory. The text for this copyright statement is provided out of the box. Let's also add a checkbox with a custom field. Locate the generic checkbox field, and select Yes for it to display to public. Let's not make this one mandatory. Click Save when you're done. This adds the checkbox, but to display text beside it, you will need to customize the label. This is done in Alma Configuration, Discovery, Display Configuration, Labels. Find the table of the labels for your form, in this case Digitization Labels. Open the row action menu, and select Customize. In this list, find Alma Digitization, Generic Checkbox. Change the description, which will be the text displayed in the Digitization Request form next to the checkbox. Let's also change the form description. Here are the customized labels. When you're done, click Save. Back in Primo-V, when a patron requests a digitization, they will see the customized form. Here is the new description and the new checkbox. The out-of-the-box copyright statement is set to display, and it has been made a mandatory field. Next, how to customize the location information. This tells patrons where to find physical items. The brief item display is the part that shows even when the section is collapsed. Expand to see the full item display. In Alma Configuration, go to Discovery, Get It Configuration, Items Display Configuration. Here you can customize the location information. To edit the content in a row or change the label, click on the row action menu, and select Edit. Not defined means no label will be displayed. You have the option to change the label. Click the globe to assign different labels for different languages. Click Done. A label for the brief item display has now been added. In the full item display, let's add a field. Click Add Field, and select the field from the drop-down. Let's add a label. Click Done. Here's how the location information looks now. Electronic service links are flexible additions to the full record, such as searching for the book on Google or Amazon. To configure these links, in Alma Configuration, you'll go to Fulfillment, Discovery Interface Display Logic, General Electronic Services. This page will list all currently configured services. You can use the toggles to activate or deactivate them, as well as select Edit from the row action menu to make changes. As an example, let's see how you would add a new service for Iliad. Click Add Service. In the pop-up, enter the requested information. The service code and name are for internal use. You can add a description if you like. The public name is the label that will display to the patron. The public note will be displayed beneath the public name. Next, you'll select whether this is a Document Delivery ILL service. Please note, if you select No here, this service will be listed in the Links section. If you select Yes, you will also need to choose a display location, such as in the Request section or the View Online section. URL Template is the web address where the patron will be redirected when they click on this link. For more information about how to format this field, please visit the Knowledge Center. When you're done, click Add and Close. Your new service has now been added. To make changes, click the row action menu and select Edit. Here you can make changes to the service details and configure the Service Availability Rules, which determine if a service should be displayed to the user. Please note, the default General Electronic Services rule is applied. That rule says Display is False, which means by default the service will not be shown to the patron in PrimoV. However, you can add a Display Rule. Click Add Rule. Name it. Click Add Parameter. In this case, our input parameter is that the ISBN field is not empty. Click Add Parameter. Then for Output Parameter, select True. In this case, the service will display if there is an ISBN for the resource. For more information about how to manage these Display Logic rules, please visit the Knowledge Center. The order of the displayed links can be managed in Alma Configuration by navigating to Fulfillment, Discovery Interface, Display Logic, General Electronic Services Order. Additionally, there are separate configuration pages to set the order for digital viewers, online services, and locations. You now know how to configure request forms, location information, and links. Thanks for watching!
