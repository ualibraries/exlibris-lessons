What you see here is the default template provided for PrimoV, but you are encouraged to customize the user interface for each of your views to match your institutional branding. Craft a landing page that reflects your institution or the target audience for each of your views. In this session, you will learn how to customize the logo and its clickable link, the favicon and the title of the browser page, the theme color, the homepage banner background image and text, and the homepage HTML. Some of the user interface customization is configured within Alma, and the changes can be seen immediately. For other elements, the customization package must be downloaded, edited and then uploaded. Let's start with changes to the customization package. In Alma, open Discovery, Display Configuration, Configure Views. Find the view you want to customize. Notice that the view code starts with the institution name and then the view name with a colon in between. Let's copy the view code now because we will need it later. Click the row action tool and select Edit. Select the Manage Customization Package tab. Under Download Package, choose which package to download. The Template View Customization Package is the default provided out of the box. If you have already made some changes to this view, you can start with the current view customization package and make additional changes. A central customization package could be relevant for consortia that have unified branding, which can then be customized per institution. For this example, download the Template View Customization Package. Open your downloads to see the zipped file. Move it to a different folder if you wish, and extract it. Inside the template package is a folder called View Code. This must be changed to the code for your view. We'll paste the view code that we copied before. The colon is not a valid character, so instead place a hyphen between the institution name and the view name. Now you can start customizing. You will need to find or create files of the images you want to use. Here we have a PNG file for the logo, an SVG file for the background image, and a favicon in .ico format. There are online tools to convert an image file to .ico format. Open the Assets folder. This contains all the elements that make up your view. Let's start by changing the logo and the favicon. Open the Images folder. Place this default logo with a PNG file of your logo, keeping the same file name, library-logo. For the favicon, open the Icons folder. Add your favicon, with the name favicon.ico. Next let's change the homepage background image. In the Homepage folder add an SVG file of the image, and name it homepage underscore background dot SVG. Also in the homepage file is the template file of the entire homepage in HTML. Before you edit it, make a copy of this file, and remove the tmpl suffix. Now you can open the page with an HTML editor, and make any changes you wish. For example, let's change this label from FAQ to Help. Feel free to delete a whole section if it doesn't serve you. Save your changes. For multiple UI languages, create a separate homepage file for each language, with the relevant language code. Patrons will be able to select which language version to display. Those are some basic changes that anyone can make to the user interface. If you or someone on your team has experience with CSS or JavaScript, you can customize these as well in the relevant folders. When you are finished customizing the package, zip the file that you renamed to match your view. Back in Alma, on the View Configuration page, and the Manage Customization Package tab, upload your updated customization package. Click the folder button to locate your zipped file, then click Open. Now click Upload. Your customization package has been successfully uploaded. Click Save to apply your changes. Now let's look at some customizations available within Alma. Here on the Manage Customization Package tab, you can choose a color theme. This theme affects many visual elements of the UI while adhering to accessibility guidelines for color and contrast. To specify a link for the logo, select the General tab. In the Logo Clickable URL field, enter the webpage address. When a patron clicks on the logo, they will be taken to this webpage. Click Save. Some important labels are changed in Alma Configuration. Open Discovery, Display Configuration, Labels. To customize the titles of the browser tabs, locate the table for Header Footer Tiles, click the Row Action button, and then Customize. Each code can then be customized. Change the description of the main title to customize the label of the browser tab. Click Customize to save your changes. The large text on the landing page banner is controlled with the label nde.landing.header. Search for this code to find its table. Click the Row Action button, and then Customize. Again, search for this code. In this case, there is a default landing header, but each view can have a different one. To create a unique landing header for a view, click Add Row. Input the name of the view, followed by a dot, and then the label code. Select the description that you want to display. Click Add Row. Here it is. Click Customize to save your changes. Learn more in the session dedicated to label configuration. Open the view to see your new customized user interface. Here is the new logo, favicon, and browser tab title. Notice the new theme color, and the changes to the homepage. More advanced customizations are available, including generating your own color theme, developing your own custom components, and integrating with third-party systems using add-on configuration in Alma.
