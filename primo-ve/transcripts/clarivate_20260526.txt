Hello, as an administrator, you will need to configure how and what users see when they are using Primo-V by managing the various views. Views in Primo-V define everything you want to show the patron, and it's where they can conduct searches, retrieve results, and access materials. You can have multiple views per institution, as there is no limit, such as a test view, a demo view, and a production view, or each library branch can have a different view. In this session, you will learn how to configure and manage each view, including how to create a new view and edit an existing one. Please note, configuration for Primo-V is done through Alma. To access views, you'll go to Discovery, Display Configuration, Configure Views. Here you can see a list of all the views currently at your institution, and that there are a few views that have already been defined. The default view is marked by the blue radio button. This is the view used when staff use the Display and Discovery link from a record. If you need to create a new view, you can either open the row action tool and select Duplicate to make a copy of an existing view, such as for a test view of your current configurations, or create a new one, which is what we'll do, so you'll click Add View. On the View Configuration page, all fields marked with a red asterisk are required. In the Define View section, the code is used to form the URL of the view. Please note that spaces and special characters are not supported. Add a name and a description if you'd like. In the General Attributes section, you'll define how long the system should wait before logging out an idle guest user, as well as signed in users. Change the default language if needed. In this case, you'll select English. For more information about the additional attributes available, please visit the Knowledge Center. When you're done, click Save and Continue to save your work and keep editing, or Save to save and go back to the list of views. And here's your new view. If you click on the Row Action tool for a view, you have several options available. Go to View will display the view in a new browser tab. To edit a view, select Edit. Here you can configure how PrimoVie will display to patrons. The General tab provides a basic overview, which shows the information you entered when you created it. Everything on the page is editable except the code, because it is linked to the URL for this view. The Links menu tab contains a list of the main menu links that are displayed in the persistent search bar at the top of the view. You can see if a link is active by the toggle in the Active column. The label shows how the link will be displayed to patrons in Discovery. You can add new links by clicking Add Link, or edit an existing link by clicking the Row Action tool and selecting Edit. The Search Profile Slots tab uses previously configured search profiles and are used to narrow down searches in the user interface. They are visible to the user when they start typing in their query. Search slots can contain one or more search profiles. You can use the toggle button in the Active column to activate or deactivate a slot. And you can use the arrows to change the order in which the slots are displayed in Discovery. By default, there are a few slots that are already configured. One that is just your local catalog, one that includes everything in your local catalog as well as the central index, and one that is only the central index. You can create your own by clicking Add a Slot. Create a code, a name, and a description, if you'd like, then toggle which search profiles to include. When you're done, click Save. And here's your new search profile slot, with your selected search profiles listed. This slot will only search and display resources and or inventory from the Education Library and the Music Library. The Advanced Search Configuration tab is where you can customize your options for advanced search. And Brief Results is where you can control facet availability, order, and other Brief Results configuration elements. For more information about these tabs, please watch the Search Configuration session. The Brief Record Display tab allows you to customize the fields and actions that appear for each record in the Brief Results popover. The Display Fields section will always be four lines, but you can change their order as well as what is displayed on each. To change the content of a line, click the row action tool and select Edit. Here you can change the delimiters that determine what is shown in the brief record. The Record Actions section shows the actions that will be available to patrons when they open a record. You can select up to three up-front actions that will be the primary three displayed. Use the toggle button to activate or deactivate an action. Lastly, the Full Record Services tab shows you the order in which elements will be displayed to patrons. Use the arrows to move a line up or down. You can also configure the way different areas will be displayed by clicking on the row action tool of its row and selecting Configure. In this session, you learned how to view, create, and edit views for PrimoVie. Thanks for watching.
